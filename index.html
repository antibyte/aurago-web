In Sekunden startklar

Wähle deinen Installationspfad: One-Liner, Docker Compose oder Build from Source.

terminal 
# One-Liner Installation (empfohlen)
# Setzt Docker, HTTPS und systemd automatisch auf
curl -fsSL https://raw.githubusercontent.com/antibyte/AuraGo/main/install.sh | bash

# Danach:
cd ~/aurago
source .env
./start.sh

# Öffne http://localhost:8088
docker-compose.yml 
services:
  aurago:
    image: ghcr.io/antibyte/aurago:latest
    ports:
      - "8088:8088"
    volumes:
      - ./data:/app/data
      - ./config.yaml:/app/config.yaml
      - ./secrets:/run/optional-secrets:ro
terminal 
git clone https://github.com/antibyte/AuraGo.git
cd AuraGo
go build -o aurago ./cmd/aurago
./aurago
FAQ

Häufige Fragen

AuraGo ist ein selbst gehosteter AI Agent für Home Labs. Er läuft als Single Binary mit zero Dependencies auf jedem Linux-Server oder Raspberry Pi. Er hat direkten Zugriff auf deine Infrastruktur, hält alle Daten lokal und arbeitet 24/7 für dich, on demand oder automatisiert.

Ja. AuraGo unterstützt Ollama out of the box für lokale Modelle wie Llama 3, Mistral und andere. Du kannst auch beliebige OpenAI-kompatible APIs oder OpenRouter nutzen.

AuraGo ist unter aktiver Entwicklung. Viele Features sind bereits stabil und werden produktiv genutzt. Es gibt gelegentlich Breaking Changes. Windows- und macOS-Support ist theoretisch vorhanden, aber nicht getestet.

AuraGo wurde Security-First entwickelt: AES-256-GCM Vault für API-Keys, bcrypt + TOTP 2FA, Sandbox für Python-Execution, HTTPS mit Auto-TLS, LLM Guardian für Tool-Call-Scanning und granularer Danger Zone mit individuellen Toggles.

Schau auf GitHub vorbei. Issues, PRs und Diskussionen sind willkommen. Das Projekt ist ein One-Man-Projekt. Jede Hilfe zählt.
